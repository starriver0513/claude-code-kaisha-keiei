SECTION 01

AI経営の全体像と5フェーズ

会社経営は、分解すると5つしかない

会社経営というと複雑に聞こえますが、やっていることを分解すると、商品を作る、集客する、販売する、運営する、経理をやる。この5つです。星川の場合、この5つ全部にClaude Codeを組み込んでいます。

AI経営がうまくいくかどうかは「AIに何を読ませるか」で決まります。AIに与える情報の質が、そのまま成果の質になります。
1

商品作成

オンラインで完結する講座形式が、制作物をすべてデータとして扱えるためAIと相性がよい。HARMの法則で需要のある領域を選ぶ。

2

集客

まずは無料で始められるSNSから。APIでリサーチを自動化し、スキル化して投稿を量産する。

3

販売

ナーチャリングで信頼を積み上げ、セミナーかVSLで商品の価値を伝えて販売する。

4

運営

ファネルの数値を見て改善を回しつつ、お客様のサポートに全力を注ぐ。

5

経理

売上が立ってからでOK。freeeとClaude Codeをつないで仕訳を自動化する。

AIに任せる範囲と、人間がやる範囲

本編でお伝えした通り、全部をAIに投げるわけではありません。手を動かす作業はほぼ任せますが、次の2つは人間がやってください。

人間がやる①：お客様の生の声を集める

無料相談やモニター指導で、実際にお客様がどんな言葉で悩みを話すかを直接聞く。AIはこれを知りません。

人間がやる②：お客様へのサポート

信頼をつくるのは口コミ、口コミを生むのはお客様の成果です。ここは自分の時間を使う価値があります。

逆に言うと、ナレッジのまとめ、リサーチ、投稿作成、資料作成、数値分析、仕訳はAI駆動で回せます。人間が集めた生の情報をAIに渡すことで、はじめてAIの出力が刺さるものになります。

どこから着手するか

SECTION 02

Claude CodeとChatGPTの使い分け

「仕事をやってくれるAI」と「質問に答えるAI」

ChatGPTでも効率化自体はできます。ただ、会社経営を任せるならClaude Codeです。違いは、実際にタスクを実行するのが誰かという点にあります。

観点 Claude Code チャット型のAI（ChatGPTなど）
位置づけ 仕事をやってくれるAI 質問に答えるAI
ファイル操作 自分のパソコンのフォルダを直接読み書きできる 毎回コピー＆ペーストで情報を渡す必要がある
外部ツール連携 X、YouTube、Chatworkなどの外部ツールも操作できる 基本はテキストのやり取りで完結する
実行者 AIが実際に作業して成果物を保存する 返ってきた回答をもとに人間が作業する
会社のデータごと任せられる。だから経営の丸投げができます。

Claude Codeの始め方

  • 公式のクイックスタートに沿ってインストールする（Claude Code クイックスタート）
  • ターミナルが苦手な方は、デスクトップアプリ版から始めても問題ありません
  • まずは自分の経営フォルダを1つ作って、そこを作業場所として開く（SECTION 03）
用語補足：ターミナル（パソコンに文字で命令を出すための画面）。Claude Codeはここから起動しますが、実際に打ち込むのは日本語の指示なので、コードを書ける必要はありません。

「放置で回る」の中身

Claude Codeは、決めた時間に決めた仕事を自動で実行させられます。本編でお話しした通り、朝8時にリサーチ、夕方に投稿の下書き、といった形で設定しておくと、自分が別の仕事をしていても裏で作業が進みます。

定期実行を設定してもらうプロンプト
毎朝8時に実行する定期タスクを作ってください。

やってほしいことは以下です。
1. 保存済みのリサーチスキルを実行して、直近で伸びている投稿を取得する
2. 取得した内容を 02_リサーチ/ に日付つきで保存する
3. その日に使えそうな投稿ネタを5個、箇条書きでまとめる

設定方法と、実行結果をどこで確認できるかも教えてください。

SECTION 04

商品作成｜HARMの法則で設計する

なぜオンライン講座形式なのか

これから商品を作るなら、オンラインで完結する講座形式をおすすめします。在庫がいらず、利益率も高く、何より制作物をすべてデータとして扱えるためAIに任せられるからです。

  • 講義動画の台本 → 元になる情報を渡せばAIが下書きを作れる
  • お客様に送る配信文 → 過去の配信を読ませれば同じトーンで作れる
  • 教材のスライド → 台本から構成を起こせる

HARMの法則｜人が本気でお金を払う4領域

何を商品にするか決めるときに、外してはいけない法則があります。人が本気でお金を払う悩みは、次の4つのどれかに必ず入ります。

頭文字 領域 商品テーマの例
H Health（健康） ダイエット、体質改善、睡眠、メンタルケア
A Ambition（キャリア・夢） 転職、独立、副業、スキル習得、AI活用
R Relationship（人間関係） 恋愛、夫婦関係、子育て、職場の人間関係
M Money（お金） 集客、売上アップ、資産形成、コスト削減
人は「あったらいいな」にはお金を払いません。「この苦痛から逃れたい」に本気でお金を払います。だから商品は「あったら便利」ではなく、悩みを解決する「痛み止め」として設計してください。

自己満足の商品になっていないかチェックする

  • 解決する悩みが、HARMの4領域のどれかに入っているか
  • その悩みは「今すぐ解決したい」レベルか（後回しにされない痛みか）
  • 自分が提供できる内容で、その痛みが実際に減るか
  • すでにお金を払って解決しようとしている人がいる領域か
商品コンセプト設計プロンプト
これから作る商品のコンセプトを一緒に設計してください。

【前提】
・私が教えられること：（ここに書く）
・過去の経験や苦労したこと：（ここに書く）
・想定しているお客様：（ここに書く）

【やってほしいこと】
1. HARMの法則（Health / Ambition / Relationship / Money）の
   どの領域に当てはまるか整理する
2. その領域で、お客様が「今すぐ解決したい」と感じる痛みを5つ挙げる
3. 痛みごとに、私の経験でどう解決できるかを対応させる
4. 商品コンセプト案を3パターン出す

注意：「あったらいいな」レベルではなく、
その痛みがないと困る「痛み止め」になっているかを基準にしてください。

実績がなくても始められます

立派な実績である必要はありません。過去に苦労したこと、コンプレックスを乗り越えた経験、人より少しだけ詳しいこと。得意なことは自分にとって当たり前すぎて価値に気づきにくいのですが、それを知らない人からすれば、お金を払ってでも学びたい知識です。

何を教えるか迷っている場合、AIの使い方を教える領域は現在需要が伸びています。実際に、AIスキルを身につけて法人向けのAI研修などで月210万円を売り上げた方や、健康・ウェルネス系の講座で月商115万円を達成した方が、講座の受講生から出ています。
SECTION 05

集客①｜APIでリサーチを自動化する

まずは無料のSNSから攻略する

集客には広告とSNSがありますが、まずはSNSをおすすめします。理由はシンプルで、無料だからです。広告も強力ですが費用がかかるので、売上が立ってから考えれば大丈夫です。

APIとは、外部サービスとAIをつなぐ窓口

SNSを伸ばすのが難しいと感じるのは、何が求められているかを手作業で調べているからです。ここでAPI（外部のサービスとAIをつなぐ窓口）を使います。

媒体 使うAPI・ツール 取得できるもの
YouTube YouTube Data API 動画情報、再生数、チャンネル情報
YouTube（分析） vidIQ 登録者数に対する再生倍率などの分析指標
X X API 投稿本文、エンゲージメント数値
Instagram Instagram Platform API 投稿情報、インサイト

リサーチは2軸で回す

軸1：コンテンツを手元に保存する

伸びている投稿の本文そのものを自分のパソコンに保存していく。溜まるほど、AIに読ませる参考資料が分厚くなる。

軸2：数字のデータを取得する

どの投稿がどれだけ見られているかを取得する。何が市場に求められているかがデータで見える。

登録者の3倍以上再生されている動画を探せば、今まさに市場に求められている企画がデータで見えてきます。企画を自分の頭だけで考えないでください。

APIキーの取り扱い

  • APIキー（サービスを使うためのパスワードのようなもの）は、.envという設定ファイルにまとめて保存する
  • APIキーの中身を、投稿・スクリーンショット・画面共有に絶対に出さない
  • Claude Codeには「.envの中身は表示しないこと」とルールを渡しておく
リサーチ実行プロンプト
SNSのリサーチをしてください。

【調べてほしいこと】
・ジャンル：（例：AI活用、ダイエット、副業）
・媒体：（例：X、YouTube）

【やってほしいこと】
1. そのジャンルで直近伸びている投稿・動画を20件取得する
2. 取得した本文を 02_リサーチ/ に日付つきで保存する
3. 数字（再生数・いいね・登録者比）を一覧表にまとめる
4. 伸びている投稿に共通するパターンを5つ挙げる
5. そのパターンのうち、私の商品と相性が良いものを指摘する

APIキーは .env から読み込んでください。
キーの中身は出力しないでください。

参考にすることとパクることの違い

伸びている企画を参考にするのは、パクリではありません。参考にするのは構成と需要だけで、中身は自分の実体験で埋めるからです。

  • 伸びている企画を土台にする（需要がある証拠なので、ゼロから発明しない）
  • そこに自分の実績、自分にしか言えない具体性、独自の切り口を足す
  • 結果として、元の企画より強い企画にする
SECTION 06

集客②｜スキル化して投稿を量産する

スキルとは、AIに渡す仕事の手順書

一連の作業を1回手順書にしておくと、次からは一言指示するだけで同じクオリティの仕事が何回でも再現されます。これがClaude Codeのスキルという機能です。

リサーチスキル

APIを組み込み、ターゲットが何を求めているかを察知して保存するところまで自動化する。

投稿作成スキル

伸びているコンテンツを参考にしつつ、自分の過去投稿と混ぜて投稿を作る。

サムネイル作成スキル

企画に合わせて、サムネイルの文字案・構図案を出すところまで型にする。

過去に投稿してきた実績がある方は、その過去投稿もAIに読ませてください。自分の口調や、反応が良かった型をスキルに反映できるので、出力の精度が一気に上がります。

スキルの作り方は、スキルクリエイターに任せる

手順書を自分で書く必要はありません。Claude CodeやCodexには、スキルを作るためのスキルが最初から入っています。スラッシュを打って「skill creator」と検索すれば出てきます。AIを作った側がまとめたスキルの作り方がそこに入っているので、そのまま使ってください。

スキル化プロンプト
これまでのやり取りを参照して、この作業をスキルにしてください。

【スキルにしたい作業】
リサーチしたデータを読んで、私の過去投稿の口調で
X投稿を3本作る

【スキルに入れてほしいこと】
1. 参照するフォルダ（02_リサーチ/ と 03_集客_SNS/）
2. 私の口調・改行の癖（過去投稿から抽出してください）
3. 投稿を作る手順
4. 出来上がった投稿の保存先

次回から一言指示するだけで同じ品質になるようにしてください。

予約投稿・分析まで含めて回す

予約投稿ツールをつなぐと、作った投稿の予約も、自分のアカウントの分析もClaude Code側で完結します。星川の場合、1回リサーチを回して、それをもとに投稿を10本20本作り、予約投稿をまとめて設定して終わり、という運用ができています。

  • リサーチスキルで需要を掴む
  • 投稿作成スキルで本数を作る
  • 予約投稿ツールでまとめて設定する（Omnisocials など）
  • 数字を見て、伸びた投稿をリサーチフォルダに戻す
本来なら外注したり、人を雇ってやるような作業がこれで回るようになります。
SECTION 07

販売①｜ナーチャリングとセミナー・VSL

オンラインの商品は、無形なので基本怪しい

講座やコンサルは形がない商品です。お客様からすれば、本当に価値があるのか分からない、詐欺かもしれない。そう思われている前提で売る必要があります。だからこそ、先に信頼を取ります。

ナーチャリングで積み上げる4つのこと

ナーチャリング（見込みのお客様に価値提供しながら信頼を積み上げていくこと）でやるのは、次の4つです。

積み上げること 具体的にやること 発信テーマの例
自分を信頼してもらう 実績やお客様の成果を発信で見せる お客様の成果報告、自分の実践記録
課題に気づいてもらう 今のままだとどうなるかを伝える 放置した場合のリスク、よくある失敗例
自己投資の大切さ 時間をお金で買う考え方を伝える 独学と学習の時間差、遠回りした経験
行動の大切さ 行動して人生が変わった話を共有する 自分の転機、受講生が動いた瞬間
恋愛と同じです。いきなり告白しても無理なので、先に信頼関係を作る。SNSやLINEの発信を見てもらって、動画を見てもらって、少しずつ信頼が溜まった状態で初めて商品の話をします。

セミナーかVSL、どちらかを必ず作る

ナーチャリングを一気に完了させられる場所が2つあります。セミナー（ライブでやる説明会）と、VSL（ビデオセールスレターの略。商品の価値を伝える販売用の動画）です。

セミナーの強み

ライブなので視聴維持率が圧倒的に高い。最後まで聞いてもらえるので、ナーチャリングが一気に決まる。

VSLの強み

動画なので何回でも使い回せる。視聴者も動画を見ることに慣れている。

文章だけで売るより、動画かライブで話すほうが強いのは、メラビアンの法則（人は言葉の中身より、見た目と声から受け取る情報で印象を決めるという法則）が働くためです。視覚・聴覚・言語の情報をすべて届けられるので、一撃で怪しさを払拭できます。

セミナー・VSLの基本構成

1

掴みと自己紹介

今日話す内容と、なぜ自分が話すのかを伝える。実績はここで出す。

2

課題の共有

お客様が抱えている悩みを、お客様自身の言葉で言い当てる。

3

価値提供

解決策の全体像を無料で出す。ここで満足度をつくる。

4

商品紹介

信頼が一番高まったところで、そのまま商品を案内する。ここまでセットで1本。

告知はLINEかオープンチャットで行う

セミナーの告知をSNSだけでやると、冷やかしのユーザーも混ざります。それに、SNSのフォロワーにはこちらから連絡できません。興味がある方だけをLINEに集めて、そこから直接届けます。

  • セミナーの中身を角度を変えて紹介する
  • 参加特典を案内する
  • 日程のリマインドを送る（前日・当日）
  • 参加できるかどうかを確認する
SNSが伸びるだけでは売上になりません。商品の価値を伝える場所に連れてきて、初めて売上になります。
SECTION 08

販売②｜プロダクトナレッジと無料相談

商品をデータ化して、AIに読ませる

セミナーやVSLの中身もClaude Codeで作っていきます。そのために必要なのが、商品のデータ化です。これをプロダクトナレッジ（AIに自分の商品を教えるための専用の資料集）と呼んでいます。

星川の場合は、UTAGE（講座の配信から決済までをまとめて管理できるツール）に商品を入れています。決済ページと会員サイトが連携するので、購入後の案内やパスワード発行といった手作業が不要になります。使っているツールは何でも構いませんが、商品の情報がひとまとまりになっている状態を先に作ってください。

プロダクトナレッジにまとめる情報

まとめる情報 中身の例 どこで使うか
商品の内容と価格 カリキュラム、サポート内容、期間、金額 商品紹介パート、LP
お客様がよく言う悩み 相談で実際に出た言葉をそのまま記録 セミナーの課題共有パート
よくある質問と回答 申し込み前に必ず聞かれること セミナー終盤、LP、配信文
お客様の成果や声 数字つきの成果、感想、変化 信頼獲得パート、発信全般

特に大事なのがターゲットインサイト（お客様が何に悩んで、何を求めているかの情報）です。これがあると、セミナー台本も販売文も、自分の商品に合った内容でAIが書けるようになります。

ナレッジのまとめはAI駆動。生の声を集めるのは人間

ナレッジをまとめる作業自体はAIに任せて大丈夫です。ただ1つだけ、人間がやってほしいことがあります。ナレッジの元になる、お客様の生の声を集めることです。

AIはお客様の生の声を知りません。例えば40代向けのダイエット講座なら、40代の方が実際にどんな言葉で悩みを話すか。これはAIが推論で書いても、絶対に刺さりません。

無料相談で生の声を集める

  • 知り合い、友人、既存のお客様に、モニターとして無料相談を依頼する
  • 無料なので協力してもらいやすく、悩みを聞いて解決策を伝えれば相手にもプラスになる
  • 売ることを考えず、聞くことに徹する
  • 録音デバイス（PLAUD など）で録音し、文字起こしまでしておく
  • 文字起こしを 05_お客様の声/ に保存する。プロダクトナレッジへのまとめはClaude Codeが自動でやってくれる

無料相談で聞く質問の例

現状と悩み

今どんなことで困っているか。いつからその状態か。過去に何を試してうまくいかなかったか。

理想と障害

どうなれたら嬉しいか。それを妨げているものは何だと思うか。何が分かれば動けそうか。

SECTION 09

運営｜数値改善とサポート

やることは2つだけ

商品ができて、集客と販売の仕組みができたら、あとは運営です。やることは、数字を改善することと、お客様をサポートすることの2つです。

ファネルのどこで人が離れているかを見る

ファネル（お客様が商品を買うまでの流れ）のどこに穴があるかを特定して、1個ずつ塞いでいきます。

見る数字 低いときに疑うこと まず試す改善
SNSからLINEへの登録率 登録する理由が弱い 特典の内容と訴求文を変える
セミナーの申込率 セミナーで得られるものが不明確 案内文で得られる結果を具体化する
セミナーの参加率 リマインドが足りない 前日・当日のリマインドを追加する
セミナーからの成約率 ナーチャリングか商品紹介が弱い 課題共有パートと価格提示の順番を見直す
  • セミナーのテーマを変えて、何回も開催してみる
  • サムネイルや案内文の表現を変えて反応を比べる
  • Xが伸びたらYouTubeやInstagramも始めてみる
  • 回すたびにナレッジが溜まるので、AIの精度も上がっていく

信頼をつくるのは口コミ、口コミを生むのはサポート

ビジネスで一番大事なのは信頼で、信頼を作るのは口コミです。では口コミはどう生まれるかというと、お客様の成果と満足です。ここは人間の出番です。

  • どんなコンテンツがあったら嬉しいか
  • どんな対応をされたら嬉しいか
  • オフ会のような場があったほうがいいか
星川の講座では、無制限の個別サポート、月1回のグループコンサルティング、オンライン作業会、週1回のライブセミナーまで、やれるサポートは全部やっています。その結果、セミナースライド作りが2〜3日から数十分になった方や、外注費を年間240万円カットできた方など、成果報告が届いています。AIで浮いた時間を全部サポートに突っ込む。これがAI経営の本質です。
SECTION 10

経理｜freee連携で仕訳を自動化する

経理は売上が立ってからでOK

売上がないのに経理を整えても意味がありません。まずは商品と集客と販売に全力を注いでください。ただ、売上が立ったあとの経理は地味に時間を食います。売上を作る仕事でもないので、ここに自分の時間を使うのはもったいない。AIに任せる価値が一番分かりやすい領域です。

設定の手順

1

freeeに登録する

クラウド会計ソフト freee会計 の有料プランに登録する。

2

アカウントを作る

法人用か個人事業主用のアカウントを作成する。両方ある場合は両方作る。

3

Claude Codeとつなぐ

MCP（AIと外部サービスをつなぐ仕組み。APIの仲間）を使ってClaude Codeと連携する。

4

仕訳ルールを決める

どの取引をどの勘定科目にするかを一度教えておく。次から自動で振り分けられる。

用語補足：仕訳（お金の出入りを帳簿に記録する作業）。勘定科目（その支出が何の費用かを分類するラベル。通信費、外注費など）。

仕訳ルールの例

取引の例 勘定科目
サーバー代、各種SaaSの月額利用料 通信費
外注スタッフへの支払い 外注費
広告出稿費 広告宣伝費
書籍・教材の購入 新聞図書費
仕訳ルール設定プロンプト
freeeと連携して、仕訳の自動化を設定してください。

【やってほしいこと】
1. 未処理の取引を一覧で出す
2. 取引内容から勘定科目を提案する
3. 繰り返し出てくる取引は、自動仕訳ルールとして登録する
4. 判断に迷う取引は、理由をつけて確認リストにまとめる

【私の仕訳ルール】
・サーバー代、SaaS月額 → 通信費
・外注スタッフへの支払い → 外注費
・広告出稿費 → 広告宣伝費
（自分のルールを追記してください）

金額や取引先の情報は、外部に送信しないでください。
仕訳のルールを最初に決めておけば、あとは自動で処理されていきます。確定申告前に領収書の山と戦う必要はもうありません。

使う前の注意

  • 最終的な申告内容は必ず自分か税理士が確認する（AIの出力をそのまま提出しない）
  • freeeのAPIキーも .env に保存し、中身は表示しない
  • 個人情報や取引先情報を含むデータを、外部サービスに渡さない

まずはここから

自分の商品や事業の情報を1つのフォルダにまとめるところから始めてください。AI経営は、AIに何を読ませるかがすべてです。フォルダに情報が溜まった分だけ、Claude Codeに任せられる仕事が増えていきます。
